Implementation Handoff

1. Color Tokens

  • --color-cream: #f8f3e7, app background and card wash.
  • --color-cream-soft: #fffaf0, elevated panels and frosted nav.
  • --color-pine: #12371f, primary CTA and active icon tone.
  • --color-sage: #7d9667, progress, secondary action, handicap badge.
  • --color-orange: #c86718, record badge, active nav underline, reactions.
  • --color-sky: #9fcfd7, ocean/sky illustration tones.
  • --color-ink: #050607, primary text.
  • --color-muted: #5c625a, secondary text.

2. Typography Scale

  • Family: Helvetica Neue, Helvetica, Arial, system sans.
  • Logo: 26px, 800 weight.
  • Date: 20px, 500 weight.
  • Greeting: 42px, 700 weight, 0.95 line height.
  • Card labels: 12px, 700 weight, uppercase.
  • Metric numbers: 34-56px, 700 weight.
  • Nav labels: 12px, 600 weight.

3. Spacing System

  • Base spacing unit: 4px.
  • Screen side padding: 28px.
  • Card padding: 18-22px.
  • Component gap: 12px, 16px, 18px, and 22px.
  • Bottom nav height: 78px plus safe-area padding.

4. Border Radius Values

  • --radius-sm: 12px, thumbnails and small controls.
  • --radius-md: 18px, stat cards.
  • --radius-lg: 22px, rank and feed cards.
  • --radius-pill: 999px, avatars, progress bars, CTA buttons.
  • Phone screen radius: 48px, frame radius: 58px.

5. Shadow and Glass Styles

  • Panel glass: translucent cream background, 1px warm white border, restrained backdrop blur.
  • Panel shadow: soft vertical depth, low-opacity pine/brown shadow.
  • Primary CTA: dark pine gradient with a compact inner highlight.
  • Navigation: frosted cream layer with a thin top divider.

6. React Native Component Breakdown

  • HomeHeader: logo, bell button, profile avatar, status-safe top spacing.
  • HomeHero: date, greeting, coastal golf-course graphic.
  • RankCard: flag badge, points, rank copy, progress bar.
  • StatCard: icon badge, label, primary metric, optional delta.
  • CTAButton: primary and secondary variants with icon, label, chevron.
  • ClubhouseCard: avatar, identity, metadata, post body, reactions, thumbnail, menu.
  • BottomNav: five-item tab bar with active fill and orange indicator.

7. Exportable Assets

  • Export the inline .course-art SVG as a reusable hero illustration.
  • Export the thumbnail SVG as a smaller ClubhousePostThumbnail asset.
  • Replace CSS/SVG avatars with real golfer profile photos in the production app.
  • Keep nav and card icons as a single stroke icon set for consistency.
